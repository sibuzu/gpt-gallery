風姿卓約

西方影視、童話、奇幻作品裡，類似這種「一聽就知道角色定位」的女性稱呼，常見的有：

* 家族／上流社會：大小姐（Lady）、千金小姐（Heiress）、貴婦（Society Lady）、女主人（Mistress of the House）、寡婦（Widow）、老處女（Spinster）、教母（Godmother）
* 王室／貴族：公主（Princess）、女王（Queen）、王后（Queen Consort）、女公爵（Duchess）、女伯爵（Countess）、男爵夫人（Baroness）、王太后（Dowager Queen）
* 奇幻／傳說：女巫（Witch）、女術士（Sorceress）、女祭司（Priestess）、聖女（Maiden/Saint）、仙女（Fairy）、精靈女王（Elven Queen）、女武神（Valkyrie）、魅魔（Succubus）
* 宗教／修會：修女（Sister）、院長嬤嬤（Mother Superior）、女牧師（Reverend）、聖母（Holy Mother）、女先知（Prophetess）
* 江湖／冒險：女俠（Heroine）、女劍士（Swordswoman）、女獵人（Huntress）、女海盜（Pirate Queen）、女槍手（Gunslinger）、賞金獵人（Bounty Hunter）
* 宮廷／宅邸：侍女（Maid）、女僕（Maidservant）、貼身女僕（Lady’s Maid）、女管家（Housekeeper）、家庭教師（Governess）、乳母（Nurse）、陪伴女官（Lady-in-waiting）
* 西部片：酒館女郎（Saloon Girl）、農場姑娘（Farm Girl）、治安官遺孀、女槍手、淘金寡婦、牧場女主人
* 黑色電影／犯罪片：蛇蠍美人（Femme Fatale）、黑寡婦（Black Widow）、黑幫夫人（Mob Wife）、歌舞女郎（Showgirl）、夜總會歌手（Torch Singer）、女偵探（Lady Detective）
* 校園／青春片：鄰家女孩（Girl Next Door）、舞會皇后（Prom Queen）、啦啦隊長（Head Cheerleader）、校花（Popular Girl）、乖乖女（Good Girl）、壞女孩（Bad Girl）
* 愛情故事：落難少女（Damsel in Distress）、灰姑娘（Cinderella）、新娘（Bride）、逃跑新娘（Runaway Bride）、舊情人（Former Flame）、神秘女子（Mysterious Woman）

最有西方「經典角色名號」感的，大概是：

**Lady、Madame、Miss、Princess、Duchess、Baroness、Mother Superior、Fair Maiden、Governess、Saloon Girl、Southern Belle、Femme Fatale、Black Widow、Prom Queen、Girl Next Door、Wicked Stepmother、Fairy Godmother、Ice Queen、Pirate Queen、Warrior Princess。**

若要和你前面的例子作氣質對照：

| 東方稱呼 | 西方常見對應                              |
| ---- | ----------------------------------- |
| 大師姐  | Senior Sister／資深女弟子                 |
| 小師妹  | Youngest Disciple／Junior Sister     |
| 大小姐  | Young Lady／Heiress／Lady             |
| 十三姨  | Aunt + 名字或排行，如 Aunt May；西方較少直接用數字排行 |
| 師娘   | Master’s Wife／Madame                |
| 聖女   | Holy Maiden／Saintess                |
| 妖女   | Enchantress／Sorceress               |
| 女俠   | Heroine／Swordswoman                 |
| 花魁   | Courtesan／Belle of the House        |
| 老闆娘  | Proprietress／Landlady               |
| 姨太太  | Mistress／Second Wife；文化含義不完全相同      |

其中最接近「十三姨」這種大家直接拿稱謂當角色名的，是 **Auntie、Madame、Lady、Miss、Mother、Sister** 加上姓名，例如 **Aunt May、Lady Catherine、Miss Marple、Madame Maxime、Mother Gothel、Sister Mary**。
